# Исторические шаблоны RU → Reykjavík

Обезличенные снимки прежней цепочки. Файлы `ru-entry-3xui.example.json` и `ru-mobile-3xui.example.json` имеют формат импорта 3x-ui. Остальные файлы предназначены для разбора конфигурации Xray.

Перед использованием замените демонстрационные значения. Подтверждение текущего состояния этих узлов отсутствует. [Контекст и ограничения](../../docs/ru-reykjavik.md).
