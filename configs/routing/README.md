# Правила v2rayN

Наборы маршрутизации для обычных профилей v2rayN. Для Custom-профиля правила задаются внутри полного Xray JSON.

- `v2rayN-employee-routing.json` — корпоративные и российские назначения напрямую, прочее через proxy.
- `v2rayN-parkskazka-routing.json` — отдельный набор корпоративной зоны.

Выберите импортированный набор активным и проверьте порядок правил. [Инструкция](../../docs/operations.md).
