# Клиентские примеры Windows

- `employee-current-xray.example.json` — обезличенный профиль по состоянию на 25 ноября.
- `employee-xray.example.json` — ранний снимок, сохранённый для истории.
- `extended-routing-xray.example.json` — отдельный расширенный набор правил.

Примеры содержат демонстрационные адреса и ключи-заполнители. Для выдачи рабочего профиля используйте [генератор](../../tools/employee-profile-generator/). Правила DNS и корпоративные маршруты проверяйте в своей сети. [Эксплуатация](../../docs/operations.md).
