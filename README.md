# parkskazkaVPN

Документация и шаблоны для VLESS + XHTTP + REALITY, Xray, 3x-ui и v2rayN. Состояние собрано по локальным экспортам и проверкам от 11–25 ноября 2026 года.

| Схема | Состояние по источникам | Где смотреть |
| --- | --- | --- |
| Windows → VPS на TCP 443 | Профиль проверен на ПК 25 ноября. HTTPS через VLESS вернул `200 OK`. | [Эксплуатация](docs/operations.md), [клиентские шаблоны](configs/windows/) |
| Windows/телефон → RU-entry на TCP 41686 → Reykjavík | Историческая цепочка. Маршрут подтверждался на RU-узле. Мобильное подключение отдельно не подтверждено. | [Исторический снимок](docs/ru-reykjavik.md), [серверные шаблоны](configs/ru-reykjavik/) |
| MikroTik → RU-VM → Reykjavík | Проект пилота по экспорту RouterOS от 11 ноября. | [История и проект пилота](docs/ru-reykjavik.md#проект-пилота-mikrotik) |

## С чего начать

- Авторизация и хранение учётных данных — [компоненты, поток запросов и отзыв доступа](docs/authentication.md).
- Итоги проверок — [аудит REALITY от 25 ноября](docs/reality-audit-2026-11-25.md) и [DPI, мосты и ограничения маскировки](docs/dpi-and-bridges.md).
- Доступ администратора — [SSH-туннель и запуск панели](tools/admin/).
- Выдача сотруднику Windows — [генератор профилей](tools/employee-profile-generator/) и [инструкция по импорту](docs/operations.md#выдача-профиля-windows).
- Изучение маршрутов и DNS — [пример профиля от 25 ноября](configs/windows/employee-current-xray.example.json) и [правила для обычных профилей v2rayN](configs/routing/).
- Проверка 3x-ui и REALITY — [инструкция по проверке](docs/operations.md#проверка-vps-и-reality) и [скрипт аудита](tools/audit-reality.py).
- Восстановление исходного файла — каталог `local/` на компьютере, где собран репозиторий. В `local/manifest.json` указаны имена, источники и SHA-256. Этот каталог исключён из Git.

Текущий серверный inbound представлен [обезличенным примером](configs/server/reality-inbound.example.json). Это реконструкция по отчёту проверки и клиентскому профилю. Полного экспорта VPS в архиве нет. Корпоративная сеть и требования к пилоту описаны в [сетевой заметке](docs/corporate-network.md).

Репозиторий проекта — [sityzenfour/parkskazkaVPN](https://github.com/sityzenfour/parkskazkaVPN).

В шаблонах `.example.json` чувствительные поля заменены демонстрационными значениями. Перед импортом замените их данными из своего экспорта. Клиентские UUID, ключи, QR-коды, базы 3x-ui, оригинальные профили и выгрузки RouterOS хранятся локально. Для полноценного восстановления Reykjavík потребуется самостоятельный экспорт его inbound из панели.
